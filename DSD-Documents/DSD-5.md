# 5. 테스트 방안
본 프로젝트('DopamineCut')의 숏폼 인식·집계·목표 개입과 OCR·서버 분석·동기화가 정상적으로 동작하는지 단위 테스트와 통합 테스트로 검증한다.

## 5.1. 단위 테스트
단위 테스트는 개별 모듈이 의도한 기능을 독립적으로 수행하는지 검증한다. OCR 텍스트 수집·정제와 카테고리 분류의 입력·응답 처리를 중심으로 확인한다.

### 5.1.1. OCR 텍스트 추출 및 정제의 정확성을 위한 모듈 테스트 (`OCRProcessor`)
**테스트 목적**: 화면의 콘텐츠 텍스트를 추출·누적하고 UI 문구와 반복 인식을 줄이는지 검증한다.

**테스트 방법**:
  * 유튜브·인스타그램·카카오톡의 해상도와 UI가 다른 표본을 준비하여 `recognizeFrame()`의 추출 결과를 정답 텍스트와 비교한다.
  * 기본 1초 간격 수집, 중복 텍스트 정리, 영상당 최대 500자 도달 시 추가 OCR 중지를 확인한다.
  * 영상 전환·이탈 시 텍스트 확정, 댓글·공유창에서 새 캡처·CV·OCR 정지 및 기존 데이터 보존을 확인한다.

### 5.1.2. AI를 이용한 카테고리 분류의 정확성을 위한 모듈 테스트 (`CallableBatchContentClassifier`)
**테스트 목적**: OCR 텍스트가 서버 분석을 거쳐 올바른 영상의 카테고리 결과로 연결되는지 검증한다.

**테스트 방법**:
  * 카테고리별 정답 텍스트를 준비하여 Firebase 경유 Jev·조건부 Gemini 분석 결과를 비교하고, 표본 수·정확도·미확인 비율을 기록한다.
  * 최대 5개 배치·대기 기한에 따른 부분 전송과 서버의 분류 지침·텍스트 결합, 응답의 세션별 연결을 확인한다.
  * 잘못된 응답·타임아웃·한도 초과를 재현하여 미확인 처리와 재시도·대체 경로를 확인한다. 서버 분석 실패가 로컬 집계·목표 판단을 막지 않아야 한다.

---

## 5.2. 통합 테스트
통합 테스트는 앱 실행부터 인식·집계·목표 개입·서버 저장·통계 반영까지의 흐름을 검증한다. 화면 인식과 서비스 지속 동작은 **실제 안드로이드 기기**에서, 서버 검증과 접근 제어는 Firebase Emulator에서 확인한다.

### 5.2.1. 파이프라인(처리 과정)의 전체적인 동작 흐름 검증
**테스트 시나리오**:
  * **영상 진입 및 유형 판별**: 세 플랫폼의 숏폼 진입과 CV 판정을 확인한다. 일반 숏폼은 시간·영상 수, 광고는 숏폼 집계 제외, 지원되는 라이브·사진은 시간만 반영되어야 한다.
  * **영상 식별 및 집계**: 같은 영상 20초 시청 시 1회, 서로 다른 일반 영상 3개를 각각 10초 이상 시청 시 총 3회인지 확인한다. 최근 식별자 3개를 통한 재집계 방지도 확인한다.
  * **댓글·공유창 복귀**: 새 캡처·CV·OCR은 정지하고 기존 식별자·세션·텍스트를 유지하는지 확인한다. 확정된 영상의 시간은 계속 누적되며 복귀 후 추가 횟수가 없어야 한다.
  * **OCR 추출 및 AI 분류**: 영상별 누적 텍스트·서버 요청·분류 응답·카테고리 통계가 일치하는지 확인한다. 유형 판별과 의미 카테고리 분류는 구분한다.
  * **목표 적용 및 개입**: 복수 목표와 선택한 개입 방식의 동작을 확인한다. 영상 수 목표 3개에서는 다음 일반 영상의 집계 자격 확인 시 개입하고, 제한된 영상은 횟수에 추가하지 않아야 한다.
  * **장기 실행**: 동일 조건에서 앱 미실행/실행을 비교하여 배터리·온도·처리 지연·서비스 연결 및 종료 이력을 확인한다.

### 5.2.2. 목표·통계 및 Firebase 연동 검증
**테스트 시나리오**:
  * **목표 저장·복원**: `saveManagedGoalsV2`를 통해 복수 목표와 합산·개별 값, 요일별 일정, 공휴일 제외, 적용일·시간대가 저장·복원되는지 확인한다. 설정 보존과 실제 날짜별 목표 실행은 별도로 검증한다.
  * **권한 및 입력 검증**: 인증·App Check·잘못된 입력·다른 계정 접근·구버전 덮어쓰기를 확인한다. 측정 권한 해제 시 상태 표시와 복구도 확인한다.
  * **사용량 동기화**: 기본 24시간 업로드·실패 재시도·버전 충돌을 확인한다. 오프라인에서도 로컬 통계를 조회하고 복구 후 중복 집계나 갱신 누락이 없어야 한다.
  * **통계 반영**: 당시 목표에 따른 달력 상태와 기간·앱·시간/영상 수별 분석을 확인한다. 기록이 없는 과거 시간대를 임의 데이터로 채우지 않아야 한다.
  * **알림 연동**: 사용 습관 알림의 시간 선택·중복 방지와 목표·측정 상태 알림의 독립성을 확인한다.
