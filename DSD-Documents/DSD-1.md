# 1. 개발 요약

## 1.1 목적
본 프로젝트('DopamineCut')는 소셜 미디어 플랫폼의 일반 기능을 유지하면서 숏폼 콘텐츠의 과도한 사용을 관리하고, 사용자가 자신의 사용 습관을 확인하고 조절하도록 지원하는 것을 목적으로 한다. 기존의 앱 전체 실행 차단 방식과 구분하여 다음의 목적을 달성하고자 한다.
* **선택적 숏폼 관리:** YouTube Shorts·Instagram Reels·카카오톡 숏폼의 진입을 탐지하고, 콘텐츠 유형과 영상 식별 결과에 따라 시청 시간과 영상 수를 집계한다.
* **사용자 맞춤형 목표와 개입:** 최초 접속 시 기본 개입 방식을 선택하고 측정을 준비한 뒤 목표 없이 기록을 시작한다. 사용자는 누적 기록을 참고하여 숏폼 시청 시간·영상 수·앱 사용시간 목표를 복수로 설정하고, 기록만·알림·확인·제한 중 개입 방식을 선택한다.
* **기록 기반 사용 습관 확인:** 요일별 목표·공휴일 제외·앱 합산 또는 개별 설정, 목표 달성 달력과 시간대별 분석을 통해 목표 실행 결과와 사용 패턴을 확인하도록 설계한다.

이를 통해 현대인의 심각한 숏폼 시청 중독을 예방 및 관리하고 지속적인 시간관리를 통해 유저들에게 더 나은 삶을 살아가게 하는 것이 목적이다.

## 1.2 관련 기술
DRD-5에서 조사한 모바일 앱 사용시간 할당·차단 시스템 및 미션 수행 기반 사용 제한 시스템을 관련 기술로 참고한다. 현재 시스템에 사용하는 기술을 다음과 같이 정리한다.
* **모바일 화면 제어 및 트래킹:** Android AccessibilityService로 세 플랫폼의 숏폼 진입·영상 전환·화면 가림을 탐지한다. 플랫폼별 화면 해석과 공통 시청 세션·집계·목표 판단을 분리한다.
* **컴퓨터 비전 (CV):** 기기 내 모델로 콘텐츠 유형을 판별한다. YouTube는 일반 숏폼·광고·라이브·사진 게시물의 네 유형을 구분하며, 다른 플랫폼은 각 모델의 지원 유형을 공통 집계 기준에 연결한다. UNKNOWN은 별도의 학습 클래스가 아닌 미확정 처리 상태이다.
* **광학 문자 인식 (OCR):** Google ML Kit Text Recognition으로 일반 숏폼의 콘텐츠 텍스트를 기기 내에서 추출한다. 영상별로 기본 1초 간격으로 새 텍스트를 누적하고 최대 500자에 도달하면 해당 영상의 추가 OCR을 중지한다. 처리 시간에 따라 실제 간격은 늘어날 수 있다.
* **AI 기반 콘텐츠 분류:** 전환·이탈 시 확정한 영상별 OCR 텍스트를 최대 5개 단위의 배치로 Firebase Functions에 전달한다. 서버에서 분류 지침·카테고리 기준과 결합한 JSON 요청 본문을 구성하여 Jev로 전송하고, 설정된 실패 조건에서는 Gemini 대체 경로를 사용한다. 9종 카테고리로 분류하되 정보 부족·사용량 한도 초과·분류 실패는 미확인으로 처리한다. 앱에서 외부 AI 비밀키를 보유하거나 JSON 파일 자체를 업로드하는 구조는 아니다.
* **데이터 저장 및 동기화:** 실시간 시청 집계·목표 판단과 로컬 기록을 우선하고, Firebase Authentication·Firestore·Functions·App Check로 인증·검증·동기화를 처리한다. 사용량은 기본 24시간 간격으로 업로드하며 미전송 기록은 복구·재시도 대상으로 유지한다. 목표 설정 동기화는 사용량 업로드 주기와 구분한다.
* **사용 습관 알림:** 기기에서 예약·표시하며, 오전·점심·늦은 저녁 선택과 기본 08시·12시·21시 시간대를 사용한다. 사용 습관 알림의 선택은 목표·측정 상태 등 다른 알림의 여부에 영향을 주지 않는다.

## 1.3 개발 환경
* **Client (Android App):** Android Studio / Kotlin / Android XML·ViewBinding (Min SDK 26, Compile·Target SDK 36)
* **Local Storage & Async:** Android DataStore 및 로컬 파일 저장 / Kotlin Coroutines
* **Server & DB:** Firebase Authentication·Cloud Firestore·Cloud Functions·App Check / Node.js 22·TypeScript
* **AI Engine:** ONNX Runtime Android (CV) / Google ML Kit Text Recognition (OCR) / Jev·Gemini (서버 카테고리 분석)
* **형상 관리 및 협업 도구:** GitHub, Android Studio, VS Code

## 1.4 제품 요약
* **제품명:** DopamineCut (도파민컷)
* **제품 형태:** 안드로이드 애플리케이션
* **핵심 기능:**
  1. 플랫폼별 숏폼 진입 탐지·콘텐츠 유형 분류·영상 식별과 시청 집계
  2. 숏폼 시청 시간·영상 수·앱 사용시간의 복수 목표와 선택형 자동 개입
  3. 요일별 목표·공휴일 제외·앱 합산 또는 개별 설정
  4. 사용 습관 알림, 목표 달성 달력, 앱별·시간대별·카테고리별 통계

## 1.5 개발 비용
본 프로젝트는 졸업 과제(프로토타입 개발) 목적으로 진행되므로, 팀원 인건비 등의 직접 기술료는 제외하고 실제 개발 및 서비스 빌드에 투입되는 인프라 비용과 최소 운영비만을 산정하였다. 대부분의 기능을 오픈소스 및 무료 제공량(Free Tier) 범위 내에서 구현하여 비용을 최소화한다.

* **인프라 및 오픈소스 API 비용:**
  - Firebase Functions·Firestore: 0원 (Google 프리티어 범위 내 사용)
  - Google ML Kit Core (OCR): 0원 (기기 자체 온디바이스 라이브러리로 무료)
  - Jev·Gemini API 비용: 약 15,000원 (텍스트 전용 연산 및 테스트용 소액 충전)
* **협업 및 개발 도구:** 0원 (GitHub, VS Code Free 플랜 활용)

## 1.7 목표 시장
* **주 타깃층 (Core Target):** YouTube Shorts·Instagram Reels·카카오톡 숏폼의 사용을 스스로 조절하려는 10대~20대 학생 및 수험생.
* **확장 타깃층 (Sub Target):** 일반적인 앱 기능을 유지하면서 출퇴근·퇴근 후의 숏폼 시청을 관리하고 사용 변화를 확인하려는 직장인 등 성인 사용자.
* **시장 진입 전략:** 앱 전체 차단 대신 숏폼을 선택적으로 관리하는 기능을 중심으로, 기록·목표·개입·사용 변화 확인의 흐름을 제공한다. 요일별 목표와 앱 합산·개별 설정으로 생활 일정에 맞는 사용 기준을 설정하도록 한다.
