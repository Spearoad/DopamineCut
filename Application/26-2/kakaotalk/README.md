# 카카오톡 숏폼 인식 개선

## 담당 A 구현

- 숏폼 화면 표식과 영상 동작 문구를 사용해 진입 후보를 판별합니다.
- 영상 문구를 정규화한 해시로 식별하고, 300ms 안정화 후 세션을 확정합니다.
- 동일 영상의 카운터 변화는 기존 세션으로 유지하고, 영상 전환 후보는 잠시 멈춘 뒤 확정합니다.
- 댓글·공유 오버레이 시간을 제외하고, 짧은 화면 인식 공백은 최대 1.5초 유예합니다.
- 광고 판정과 다른 앱 전환은 일반 숏폼 시청시간·횟수 집계에서 제외합니다.
- 초기 진입 안정화 중 임시 세션과 시작 시각을 유지하도록 보강했습니다.
