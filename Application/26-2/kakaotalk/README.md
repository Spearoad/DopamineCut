# 카카오톡 숏폼 인식 개선 작업 기록

## 역할과 범위
- 담당: 카카오톡 파트 A(화면 탐지, 영상 전환, 시청 시간·횟수 집계 연결)
- 공통업무: 데이터 수집·라벨 검수, 모델 개선 협업, 기기별 최종 평가 결과 기록

## 데이터 수집 상태
- 이 저장소에 실제 카카오톡 캡처 데이터와 라벨 파일은 아직 없습니다.
- 포함된 `카카오톡_데이터수집_라벨링표.xlsx`는 600개 샘플 ID가 있는 빈 기록 양식입니다. 양식의 행 수는 수집 완료 수를 뜻하지 않습니다.
- 실제 화면 캡처·라벨 검수·기기/OS/카카오톡 버전 기록은 기기에서 수집한 뒤 채워야 합니다. 수집한 적 없는 자료나 실기기 평가는 완료로 표시하지 않습니다.

## 라벨 기준 초안
- `NORMAL_SHORTFORM`: 일반 숏폼 영상 화면
- `AD`: 광고/협찬/후원임이 UI 또는 표시로 확인되는 콘텐츠
- `PHOTO_POST`: 사진 한 장 또는 사진 게시물 중심 화면
- `OTHER_<유형>`: 위 유형이 아닌 콘텐츠. 발견한 기타 유형은 서로 다른 클래스로 분리
- 애매한 항목은 임의로 분류하지 않고 `OTHER_REVIEW`로 표시해 재검수
- 같은 게시물의 반복 캡처는 `duplicate_group`으로 묶어 데이터 중복을 확인
- 대화, 계정명, 프로필, 연락처 등 개인 식별 정보가 보이는 화면은 수집하지 않음

## 담당 A 구현 상태
- 진입/이탈 후보를 안정화 시간 기준으로 확정하고, 후보 상태에서 얻은 세션 키를 유지
- 같은 영상의 화면 카운터 변동만으로 새 영상으로 오판하지 않도록 식별 흐름 보강
- 짧은 스크롤 흔들림, 전환 대기, 오버레이, 광고 화면, 카카오톡 앱 이탈 상태의 세션 처리 연결
- 관련 구현과 단위 검증 내용은 상위 `전체 변경 내역.md` 및 제출용 구현 검증 기록 참조
- 카카오톡 실기기 UI 트리와 실제 동작은 확인하지 못했으므로 기기 검증 완료로 간주하지 않음
