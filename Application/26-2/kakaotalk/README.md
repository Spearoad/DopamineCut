# 카카오톡 숏폼 인식 개선

## 담당 A 구현

- 숏폼 화면 표식과 영상 동작 문구를 사용해 진입 후보를 판별합니다.
- 영상 문구를 정규화한 해시로 식별하고, 300ms 안정화 후 세션을 확정합니다.
- 동일 영상의 카운터 변화는 기존 세션으로 유지하고, 영상 전환 후보는 잠시 멈춘 뒤 확정합니다.
- 댓글·공유 오버레이 시간을 제외하고, 짧은 화면 인식 공백은 최대 1.5초 유예합니다.
- 광고 판정과 다른 앱 전환은 일반 숏폼 시청시간·횟수 집계에서 제외합니다.
- 초기 진입 안정화 중 임시 세션과 시작 시각을 유지하도록 보강했습니다.

## 담당 B 구현

- 카카오톡 화면을 숏폼 일반·숏폼 광고·지금 탭 기타·친구·채팅 4종으로 분류하는 MobileNetV3-Small 모델을 학습했습니다.
- 직접 캡처한 화면 300장을 검수해 사용했고, 같은 영상의 연속 캡처가 학습·평가에 섞이지 않도록 묶음 단위로 나눴습니다.
- 모델 4종(MobileNetV3-Small·Large, ResNet-18, 입력 방식 2종)과 학습 설정 4종을 비교해, 폰에서 빠르게 돌릴 수 있는 MobileNetV3-Small(6.1MB)을 선택했습니다.
- 테스트셋 47장에서 정확도 93.62%(44/47), Macro F1 90.67%입니다.
- ONNX로 변환해 앱에 넣고, 담당 A가 확정한 영상마다 화면을 판정해 일반 숏폼만 시청시간·횟수에 집계하도록 연결했습니다.
- 학습 코드는 [`training/`](./training/), 앱에 들어간 모델로 다시 평가한 결과는 [평가 노트북](./model_evaluation.ipynb)에 있습니다.
